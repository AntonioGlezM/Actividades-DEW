Validación con checkValidity() y validity

¿Qué se pretende entender aquí?

Este ejemplo utiliza la API nativa de JavaScript Constraint Validation para gestionar errores sin lógica manual:

  • checkValidity(): Devuelve true si el campo cumple con todos sus atributos HTML (required, minlength, type) y false si incumple alguno.
  • Propiedad validity: Objeto que indica la razón exacta del fallo (por ejemplo, e.target.validity.valueMissing si está vacío o tooShort si falta longitud).
  • validationMessage: Contiene el mensaje de error oficial del navegador adaptado al idioma del usuario.
