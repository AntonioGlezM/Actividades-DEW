Bloque 3: Uso de setCustomValidity()

¿Qué se pretende entender aquí?

Este ejemplo enseña a controlar los mensajes de la API de validación nativa usando setCustomValidity():

  • Definir mensaje propio: Con input.setCustomValidity("Tu mensaje") reemplazamos el texto genérico del navegador por uno personalizado y cercano para el alumno.
  • Regla de oro: Si le pasas un texto distinto de vacío "", el navegador considerará automáticamente que el campo es inválido.
  • Limpiar el error: Es indispensable llamar a input.setCustomValidity("") cuando la entrada sea correcta; de lo contrario, el campo quedará marcado como inválido para siempre.
  • Lectura limpia: Tras establecer o limpiar el mensaje personalizado, input.validationMessage contendrá exactamente nuestro texto.
