¿Qué se pretende entender aquí?

Este ejemplo demuestra cómo acceder a las propiedades principales que genera el navegador al presionar una tecla:

  • Diferencia entre key y code: e.key representa el carácter producido (ej. "a" o "A"), mientras que e.code identifica la tecla física accionada (ej. KeyA).
  • Teclas modificadoras: Las propiedades booleanas (altKey, ctrlKey, shiftKey, metaKey) devuelven true si la tecla correspondiente estaba pulsada durante el evento.
  • Detección de combinaciones: Permite construir atajos de teclado o atajar acciones complejas analizando el estado simultáneo de varias teclas.
