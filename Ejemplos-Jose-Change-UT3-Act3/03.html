Evento Change con Target Select

¿Qué se pretende entender aquí?

Este ejemplo demuestra cómo funciona el evento change y el uso de e.target sobre una lista desplegable (<select>):

  • Disparo inmediato: A diferencia de los campos de texto, en un <select> el evento change se dispara al instante cuando el usuario selecciona una nueva opción, sin necesidad de perder el foco.
  • Uso de e.target: e.target hace referencia directa al elemento HTML que disparó el evento (el <select>).
  • Propiedades clave: Con e.target.value obtenemos el valor del atributo value de la opción elegida, y con e.target.options[e.target.selectedIndex].text obtenemos el texto visible para el usuario.
