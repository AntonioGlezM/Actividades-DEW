Evento Input en Tiempo Real

¿Qué se pretende entender aquí?

Este ejemplo demuestra la diferencia entre detectar el cambio al instante frente a esperar el desenfoque:

  • Evento input: Se dispara instantáneamente cada vez que el valor del campo cambia (al escribir, borrar, pegar texto con el ratón, etc.). No requiere perder el foco.
  • Diferencia con change: Mientras que change espera a que salgas del campo (o pulses Enter), input reacciona carácter por carácter en tiempo real.
