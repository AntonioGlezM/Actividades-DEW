¿Qué se pretende entender aquí?

Este ejemplo demuestra cómo actualizar dinámicamente el contenido de un <select> según la opción elegida en otro:

  • Lectura del valor con this.value: Obtenemos el género seleccionado directamente desde la opción activa del primer desplegable.
  • Búsqueda en un objeto (diccionario): Usamos la clave elegida (ej. "Pop") para obtener el array correspondiente en cantantesPorGenero.
  • Reinicio de opciones con innerHTML: Vaciamos el select secundario antes de cargar nuevos elementos para evitar acumular datos antiguos.
  • Inserción de nodos con createElement: Recorremos la lista con forEach, creamos etiquetas <option> e insertamos cada una con appendChild().
