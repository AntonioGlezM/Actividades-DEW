¿Qué se pretende entender aquí?

Este Task Board practica la gestión avanzada de eventos con JavaScript nativo:

  • 1. e.preventDefault(): Inhibe la acción nativa del evento: evita que el formulario recargue la página (submit) y que se abra el menú contextual (contextmenu).
  • 2. Delegación de eventos: Un único listener click en el <ul> gestiona la selección y la eliminación de todas las tareas, también las creadas después.
  • 3. e.stopPropagation(): Detiene el burbujeo: al pulsar "Eliminar" el clic no sigue subiendo por el DOM.
  • 4. e.target: Es el elemento real que originó el evento. Con closest('[data-accion]') localizamos qué acción corresponde (eliminar o seleccionar).
  • 5. Eventos de ratón y selección: mouseover/mouseout para el efecto hover, contextmenu para bloquear el clic derecho y selectstart para evitar resaltar texto sin querer.
